# YOLOv8 Object Detection and Tracking

A computer vision project that performs object detection and multi-object tracking in video files using YOLOv8, ByteTrack, and OpenCV.

The application processes video frames, detects objects, tracks them across consecutive frames, and generates an annotated video containing detection results and tracking IDs.

## Features

- Object detection using YOLOv8
- Multi-object tracking with ByteTrack
- Persistent tracking IDs across video frames
- Confidence threshold configuration
- Bounding box visualization
- Annotated video output
- Live preview of processed frames
- Keyboard control to stop processing

## Technologies Used

- Python
- YOLOv8
- Ultralytics
- OpenCV
- ByteTrack

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/yolov8-object-tracking.git
cd yolov8-object-tracking
```

Replace `YOUR_USERNAME` with your GitHub username.

### 2. Create a Virtual Environment

On Windows:

```bash
python -m venv .venv
```

Activate the environment in PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Install Dependencies

Create a `requirements.txt` file containing:

```text
ultralytics
opencv-python
```

Install the dependencies:

```bash
python -m pip install -r requirements.txt
```

Python, PyTorch, and other required packages may be installed as dependencies of Ultralytics.

## Usage

### 1. Prepare the Input Video

Place your video file in the project directory and update the following variable in `main.py` if necessary:

```python
video_path = "IMG_5268.MOV"
```

### 2. Run the Application

```bash
python main.py
```

The application loads the YOLOv8 nano model, processes the video frame by frame, detects objects, and tracks them using ByteTrack.

### 3. View the Results

- A live preview displays the annotated video.
- Bounding boxes and tracking IDs visualize detected and tracked objects.
- The processed video is saved as `output.avi`.
- Press `q` to stop processing.

## Model Configuration

The project uses the YOLOv8 nano model:

```python
model = YOLO("yolov8n.pt")
```

The tracking configuration uses the following parameters:

| Parameter | Value | Description |
|---|---|---|
| `conf` | `0.3` | Minimum detection confidence threshold |
| `iou` | `0.5` | IoU threshold used by the prediction pipeline |
| `persist` | `True` | Preserves tracking state across consecutive frames |
| `tracker` | `bytetrack.yaml` | Selects the ByteTrack tracker |

## How It Works

1. Load the YOLOv8 model.
2. Open the input video using OpenCV.
3. Read the video frame by frame.
4. Detect objects and associate detections across frames using ByteTrack.
5. Draw bounding boxes and tracking information.
6. Display the annotated frames.
7. Save the processed frames to an output video.
8. Release video resources when processing ends.
